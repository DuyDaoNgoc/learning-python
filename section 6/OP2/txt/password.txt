- Import thư viện re để dùng regex kiểm tra mật khẩu.

- Import thư viện secrets để tạo ký tự ngẫu nhiên bảo mật cao.

- Import thư viện string để lấy chữ cái, số và ký tự đặc biệt có sẵn.

- Khai báo hàm generate_password() với:
  + length = 16 → độ dài mật khẩu
  + nums = 1 → ít nhất 1 chữ số
  + special_chars = 1 → ít nhất 1 ký tự đặc biệt
  + uppercase = 1 → ít nhất 1 chữ in hoa
  + lowercase = 1 → ít nhất 1 chữ thường

- Tạo biến letters:
  string.ascii_letters
  chứa tất cả chữ thường và chữ in hoa.

- Tạo biến digits:
  string.digits
  chứa các số từ 0 đến 9.

- Tạo biến symbols:
  string.punctuation
  chứa các ký tự đặc biệt.

- Gộp letters + digits + symbols
  vào biến all_characters.

- Dùng while True để lặp cho tới khi tạo được mật khẩu hợp lệ.

- Tạo biến password = ''
  để khởi tạo chuỗi rỗng.

- Dùng vòng lặp:
  for _ in range(length)

  để tạo mật khẩu theo độ dài yêu cầu.

- Mỗi lần lặp:
  secrets.choice(all_characters)

  sẽ lấy ngẫu nhiên 1 ký tự trong all_characters.

- Nối ký tự vừa lấy vào password.

- Tạo danh sách constraints
  chứa các điều kiện kiểm tra mật khẩu.

- (nums, r'\d')
  kiểm tra số lượng chữ số.

- (special_chars, fr'[{symbols}]')
  kiểm tra ký tự đặc biệt.

- (uppercase, r'[A-Z]')
  kiểm tra chữ in hoa.

- (lowercase, r'[a-z]')
  kiểm tra chữ thường.

- Dùng all()
  để kiểm tra tất cả điều kiện.

- re.findall(pattern, password)
  dùng regex tìm các ký tự phù hợp trong password.

- len(re.findall(...))
  dùng để đếm số ký tự tìm được.

- Nếu tất cả điều kiện đúng:
  break
  để thoát khỏi while.

- return password
  trả về mật khẩu hoàn chỉnh.

- if __name__ == '__main__':
  kiểm tra file có đang được chạy trực tiếp hay không.

- new_password = generate_password()
  gọi hàm tạo mật khẩu.

- print()
  dùng để in mật khẩu ra màn hình.
